=== NFR-1 Trust

.Acceptance criteria
. The actions contain no key, signer or project-specific value.
. Only jobs with `environment: release` read `RELEASE_ALLOWED_SIGNERS`; the environment admits
  release tags only. The allowed signers are written to a temporary file that is removed after
  the check.
. Only the publishing job gets `contents: write`.
. The asciidoctor image is pinned by tag and digest.
